Core Architecture

Engineered For Autonomous Pair Programming

Autonomous Agent Planner

Multi-step tool calling engine. Reads files, queries AST trees, builds dependency graphs, executes terminal commands, and drafts unified diff proposals.

Isolated Git Worktrees

AI modifications occur in isolated worktrees. Your active local branch remains pristine until you review and accept proposals.

Dynamic Multi-LLM Router

Switch between Groq (Llama 3.3, GPT-OSS) and Google Gemini (Gemini 2.5 Flash, Pro), or configure any custom model ID present with your key.

AST & Neural Embeddings

Tree-sitter symbol indexing combined with local Chroma vector search. Finds related definitions, calls, and types across large repositories.

Monaco Code Studio

Full VS Code editing fidelity with syntax highlighting, inline diff visualization, multi-tab layout, and real-time streaming code completions.

Safety Policy & Change Ledger

Protection against unwanted modifications. Every operation is tracked in an auditable ledger with one-click checkpoint rollback.

FAQ

Frequently Asked Questions

You can access the live hosted demo version at https://blaid.duckdns.org directly in your web browser with zero installation needed.
Crystal natively routes between Groq (Llama 3.3 70B, GPT-OSS 120B) and Google Gemini (Gemini 2.5 Flash, Gemini 2.5 Pro). You can also configure any custom model ID present with your key or point to local endpoints (Ollama / vLLM).
Rather than modifying files directly on your active working branch, Crystal creates an isolated Git worktree branch for AI proposals. Edits, tool runs, and test executions happen in the sandbox. You review the diff and choose whether to accept or discard.
Closing the Crystal desktop window automatically terminates the background server. If running standalone, execute crystal stop from any terminal.
